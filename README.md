# Kumo Koi

A cozy koi-breeding game in a pastel cloud-pond: pair koi in spring, sort hundreds of fry by eye, raise the
keepers, sell the rest, dig new ponds, shoo herons and win ribbons at the autumn koi show.
**Play it at https://demidummy.github.io/kumo-koi/**

Click a koi to select it, Sort & cull to pick keepers, Space to pause, 1 2 3 for speed, F to feed.

This repo only holds the built game. It's published from a private source repo by tools/release-pages.sh.
